# Автоматическая классификация литологических типов горных пород

Проект по разработке воспроизводимого пайплайна машинного обучения для автоматической классификации литотипов по комплексу каротажных кривых на основе открытого набора данных **FORCE 2020 Machine Learning Lithology Competition**.

## Описание проекта

Целью данного проекта является создание ML-модели, способной с высокой точностью предсказывать литологическую колонку в скважине по каротажным данным. Модуль решает задачи предобработки сырых данных, их очистки, синхронизации по глубине, обучения классификаторов и оценки качества моделей на независимых скважинах (well-based hold-out).

## Входные данные

В качестве признаков используются следующие геофизические исследования скважин (ГИС):

- **GR** (гамма-каротаж)
- **RHOB** (плотностной каротаж)
- **NPHI** (нейтронная пористость)
- **DT** (акустический каротаж)
- **SP** (самопроизвольная поляризация)
- **RDEP / RMED / RSHA** (кривые удельного электрического сопротивления различной глубинности исследования)

**Целевая переменная:**
Коды/метки литологических классов (литофаций) — поле `FORCE_2020_LITHOFACIES_LITHOLOGY`.

## Основные этапы пайплайна

1. **Предобработка и очистка данных:**
   - Загрузка данных из форматов `.las` (с помощью `lasio`) или `.csv`.
   - Раздельная обработка пропусков: служебные значения `-999.25` для файлов заказчика и `NaN` для датасета FORCE 2020.
   - Очистка выбросов и нештатных значений.
   - Ресемплинг и синхронизация кривых по единой шкале глубины (`DEPTH` / `DEPT`).
   - Явная обработка отсутствующих каротажных кривых в отдельных скважинах.

2. **Обучение моделей классификации:**
   - **Baseline:** Логистическая регрессия (Logistic Regression).
   - Случайный лес (Random Forest).
   - Градиентный бустинг (XGBoost или CatBoost).
   - Учет дисбаланса классов: `class_weight` для классификаторов scikit-learn, `sample_weight` / `class_weights` для градиентного бустинга.

3. **Валидация и метрики:**
   - Разделение выборки по скважинам (well-based hold-out) для исключения утечки данных.
   - Оценка качества: `accuracy`, `precision`, `recall`, `F1-score` (macro и weighted), построение матрицы ошибок (confusion matrix).
   - Оценка качества по официальной penalty-матрице конкурса FORCE 2020.
   - Визуализация результатов: построение прогнозной литологической колонки рядом с истинной вдоль шкалы глубин, а также оценка важности признаков (feature importance).

## Быстрый старт

### Установка зависимостей

Для установки необходимых библиотек используйте:

```bash
pip install -r requirements.txt
```

### Подготовка данных

Для запуска экспериментов необходимо загрузить файлы данных и поместить их в директорию `data/` (создайте её в корне проекта, если она отсутствует):

1. **Набор данных FORCE 2020:** Скачайте файл обучающей выборки `CSV_train.csv` (а также при необходимости `CSV_test.csv` для тестирования) из официальных источников:
   - Официальный репозиторий конкурса на GitHub: [bolgebrygg/Force-2020-Machine-Learning-competition](https://github.com/bolgebrygg/Force-2020-Machine-Learning-competition) (в папке `lithology_competition/data`)
   - Google Drive папка организаторов: [FORCE 2020 Lithofacies Prediction Data](https://drive.google.com/drive/folders/0B7brcf-eGK8CRUhfRW9rSG91bW8)
2. **Штрафная матрица (Penalty Matrix):** Скачайте файл `penalty_matrix.npy` с весами ошибок классификации из тех же источников и сохраните его как `data/penalty_matrix.npy`.

Структура папки `data/` должна выглядеть следующим образом:
```text
data/
├── CSV_train.csv
├── CSV_test.csv
└── penalty_matrix.npy
```

### Воспроизводимость

Все этапы пайплайна используют единый зафиксированный параметр `random_state` из модуля `src/config.py` для обеспечения полной воспроизводимости результатов.
